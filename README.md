The first issue WAVE reported was an empty link. This is bad because if a link contains no text, then it will not function and can cause confusion for users.
Another issue WAVE reported was 8 redundant links. This means adjacent links go to the same location and this affects the reliability of the website, creating confusion and extra navigation for users.
A third issue WAVE reported was small text. This affects the users visibility. Small text causes the website to become hard to read.
Using WAVE to double check my work made me realize how small coding oversights can ruin the user experience for website visitors. Looking at the results, I learned how important it is to give every link, clear descriptive text. Finding an empty link showed me that without context a link basically leaves website visitors completely lost on where it goes or what the purpose is. Seeing 8 redundant links also made me realize how easily clutter builds up. When links right next to eachother lead to the same exact page, it forces website users to click and tab through extra stuff making the website feel messy and unreliable. Lastly, WAVE reporting a small text error, made me realize the importance of basic readability. If text is too tiny to read comfortably, website visitors could get frustrated and leave. In all, fixing these issues taught me that building a good website isnt just about making things look fun or right on my own screen but also taught me to consider the users and their comfortability and accessibility to my website.
